# Sortly UI screenshots (visual source of truth)

Use these images to match **layout, spacing, typography, teal accent, and dialog chrome**. Do not copy Sortly’s logo or wordmark.

Captured read-only from Primary’s account, 21 Aug 2026. Most shots: viewport **1440×900**. **Dashboard** (`01`) and **All Items** (`02`) retaken at **1920×1080** so the **expanded left sidebar** (icon + label + company logo) is readable. Pages were waited until unique content (and card photos) loaded. Dialogs were opened then **cancelled** — no Print & Save, Clone, Update, Move, Export, or Add.
